# HorseMatch

HorseMatch este o aplicație web de dating pentru cai. Proprietarii de cai și administratorii de herghelii o pot folosi pentru a găsi potențiale perechi și a lua legătura atunci când interesul este reciproc.
# Funcționalități propuse
- Conturi de utilizator — înregistrare și autentificare pentru proprietari și administratori de herghelii.
- Profiluri pentru cai — adăugarea și editarea profilurilor cu fotografii, rasă, vârstă, sex, localitate și o scurtă descriere.
- Căutare și filtrare — explorarea profilurilor după rasă, interval de vârstă, sex și localitate.
- Exprimarea interesului — selectarea unui cal propriu și marcarea unui profil de interes pentru acesta.
- Potriviri reciproce — înregistrarea unei potriviri când ambii proprietari își exprimă interesul pentru aceeași pereche de cai.
- Mesagerie privată — posibilitatea de a începe o conversație după o potrivire.
